## 📖 Overview

The **All-in-One SEO Analysis Tool** is a modern, fully-responsive web application designed to give website owners, digital marketers, and SEO professionals a complete picture of any website's health. With a sleek landing page and a feature-rich analytics dashboard, the tool centralizes critical SEO and performance data into one clean, easy-to-navigate interface.

The application is structured as a two-part experience:

- **HomePage** — A visually engaging landing page where users enter any website URL to kick off a comprehensive analysis.
- **Dashboard** — A powerful 12-section analytics panel that breaks down every aspect of a site's SEO, security, and performance.

---

## ✨ Key Features

### 🏠 Landing Page (`HomePage.html`)
| Feature | Description |
|---------|-------------|
| 🎬 **Animated Video Background** | Full-width, autoplaying background video that gives the page a modern, dynamic feel |
| 🔗 **Website URL Analysis Form** | Central input field with validation to submit any URL for analysis |
| ⚡ **Performance Analysis** | Insights into loading speed and Core Web Vitals |
| 🔍 **SEO Analysis** | Full audit of meta tags, headings, and content structure |
| 🛡️ **Security Check** | SSL validation and vulnerability scanning overview |
| 🧩 **Technical SEO** | Schema markup, sitemap, and robots.txt validation |

### 📊 Analytics Dashboard (`dashboard.html`)
| Section | Description |
|---------|-------------|
| 📈 **Performance Metrics** | Overall performance score & grade, SEO score, Core Web Vitals (FCP, TTFB, load time), regional performance (USA, Canada, France), timing metrics, and improvement recommendations |
| 🔎 **Indexing & Crawlability** | Indexed pages, crawled pages, search rankings, competitor analysis, and sitemap status |
| 🏷️ **Meta Data & Structure** | Meta description, title, broken links, H1/H2/H3 tag hierarchy, duplicate content, and keyword tag badges |
| 🚦 **Traffic Profile** | Traffic analytics panel with status indicators and retry mechanism |
| 🔑 **Keyword Analysis** | Top-performing keywords table with rank, search volume, and difficulty scores |
| 🔗 **Backlink Analysis** | Total backlinks, unique referring domains, and toxic backlink warnings |
| 📣 **Social Media Profile** | Follower metrics for Facebook, Twitter, and LinkedIn |
| 📍 **Google Local Search** | Google My Business verification and local pack rankings |
| 🧬 **Schema Markup** | Schema implementation status for Organization, Article, and Product types |
| 🔐 **Security & SSL Data** | SSL certificate validity, expiration countdown, issuer & subject details, malware risk detection |
| 🌐 **Domain Data** | Domain age, expiration, registrar, SSL status, hosting provider, and DNS configuration |
| 👥 **User Data** | Admin panel-style user management table with edit/delete actions |

### 🎨 UI/UX Highlights

## 🚀 Getting Started

1. **Open the landing page** — Load `HomePage.html` in any modern browser (Chrome, Firefox, Edge, Safari).
2. **Enter a website URL** — Type or paste a URL (e.g., `https://example.com`) into the analysis field.
3. **Click "Analyze Website"** — The form submits to `analyze.php` (backend integration point).
4. **Explore the dashboard** — Navigate the `dashboard.html` sidebar to review each SEO/performance category.

No build tools, package managers, or servers are required — the project runs directly in the browser.
